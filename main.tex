\chapter{GIỚI THIỆU ĐỀ TÀI}

\section{Đặt vấn đề}

Du lịch ẩm thực đường phố là loại hình du lịch hấp dẫn tại TP. Hồ Chí Minh. Đường Vĩnh Khánh, Quận 4 nổi tiếng với hàng trăm quán ăn hải sản và món ăn địa phương. Tuy nhiên, du khách quốc tế thường gặp khó khăn: tìm kiếm quán ăn chất lượng, hiểu thực đơn khi không biết tiếng Việt, và lập kế hoạch tuyến đường khám phá hợp lý.

Nhóm xây dựng ứng dụng \textbf{VinhKhanh Explorer} -- ứng dụng hướng dẫn âm thanh du lịch ẩm thực đường phố, giúp du khách khám phá ẩm thực đường Vĩnh Khánh thông qua bản đồ tương tác, mã QR, âm thanh đa ngôn ngữ và các tour ẩm thực có sẵn.

\section{Mục tiêu đề tài}

\begin{itemize}[nosep]
  \item Xây dựng ứng dụng web hỗ trợ du khách khám phá ẩm thực đường Vĩnh Khánh.
  \item Tích hợp bản đồ tương tác với định vị GPS và hiển thị các điểm ẩm thực (POI).
  \item Hỗ trợ đa ngôn ngữ (22 ngôn ngữ) với Text-to-Speech tự động.
  \item Xây dựng hệ thống quản lý nội dung cho quản trị viên và chủ quán.
  \item Tích hợp mã QR để du khách truy cập nhanh thông tin địa điểm.
  \item Cung cấp các tour ẩm thực có sẵn với tuyến đường đi bộ.
\end{itemize}

\section{Phạm vi đề tài}

\begin{itemize}[nosep]
  \item \textbf{Frontend web:} React 19 + TypeScript, bản đồ Leaflet.
  \item \textbf{Backend API:} ASP.NET Core (.NET 10), cơ sở dữ liệu SQLite.
  \item \textbf{Mobile:} .NET MAUI (prototype).
  \item \textbf{Đối tượng:} Du khách, chủ quán ăn, quản trị viên.
  \item \textbf{Khu vực:} Đường Vĩnh Khánh, Quận 4, TP.HCM.
\end{itemize}

\chapter{CƠ SỞ LÝ THUYẾT}

\section{ASP.NET Core và .NET 10}

ASP.NET Core là framework mã nguồn mở, đa nền tảng của Microsoft để xây dựng ứng dụng web và dịch vụ API. Các đặc điểm chính: đa nền tảng (Windows, Linux, macOS), hiệu năng cao, hỗ trợ Dependency Injection tích hợp sẵn, Middleware Pipeline, và Entity Framework Core cho truy xuất cơ sở dữ liệu.

\section{React và TypeScript}

React là thư viện JavaScript phổ biến nhất để xây dựng giao diện người dùng. Đồ án sử dụng: Functional Components, React Hooks (useState, useEffect, useContext), Context API quản lý trạng thái toàn cục, Custom Hooks tái sử dụng logic, React Router với lazy loading, và Protected Routes bảo vệ trang theo vai trò.

\section{JWT (JSON Web Token)}

JWT là chuẩn mở (RFC 7519) truyền thông tin an toàn dưới dạng JSON. Trong đồ án, JWT dùng để xác thực người dùng (Admin và Owner), phân quyền truy cập API dựa trên vai trò, và hỗ trợ Refresh Token gia hạn phiên đăng nhập.

\section{Leaflet và OpenStreetMap}

Leaflet là thư viện JavaScript mã nguồn mở xây dựng bản đồ tương tác. Đồ án sử dụng Leaflet kết hợp OpenStreetMap để: hiển thị bản đồ đường Vĩnh Khánh, đánh dấu các điểm ẩm thực, hiển thị tuyến đường tour, định vị GPS người dùng, và hỗ trợ chế độ sáng/tối.

\section{Text-to-Speech và QR Code}

Hệ thống sử dụng Microsoft Edge TTS (edge-tts) chuyển đổi văn bản sang giọng nói, hỗ trợ 22 ngôn ngữ. Mã QR được tạo bởi thư viện QRCoder, gắn với mỗi điểm ẩm thực để du khách quét và truy cập nhanh thông tin.

\section{Sơ đồ Use Case}

\subsection{Use Case -- Du khách (Visitor)}

Du khách có thể thực hiện các chức năng: Xem bản đồ tương tác, Quét mã QR, Kích hoạt tài khoản (thanh toán 20.000 VND / 24h), Xem chi tiết POI, Nghe âm thanh hướng dẫn đa ngôn ngữ, Xem tour ẩm thực, Lưu địa điểm yêu thích, Đánh giá địa điểm.

\subsection{Use Case -- Chủ quán (Owner)}

Chủ quán có thể: Đăng ký tài khoản, Đăng nhập, Quản lý POI của mình, Quản lý thực đơn (CRUD món ăn), Quản lý hình ảnh, Quản lý mã QR, Xem thống kê, Xem thông báo.

\subsection{Use Case -- Quản trị viên (Admin)}

Admin có thể: Quản lý toàn bộ POI, Duyệt POI mới, Duyệt Owner đăng ký, Quản lý danh mục, Quản lý Tour ẩm thực, Quản lý ngôn ngữ, Quản lý mã QR, Xem báo cáo thống kê, Xem audit log.

\section{Kiến trúc hệ thống}

Hệ thống được xây dựng theo kiến trúc 3 tầng (3-tier):

\begin{itemize}[nosep]
  \item \textbf{Client Tier:} React Web App (Visitor/Admin/Owner) và .NET MAUI Mobile App.
  \item \textbf{API Tier:} ASP.NET Core Web API với JWT Auth Middleware và Swagger API Docs.
  \item \textbf{Service Layer:} POI Service, Tour Service, Audio/TTS Service, Translation Service, QR Service, Visitor Service, Owner Service.
  \item \textbf{Data Tier:} SQLite Database (EF Core) và File Storage (wwwroot -- hình ảnh, âm thanh, QR).
  \item \textbf{External Services:} Edge TTS (Python) và Google Translate API.
\end{itemize}

\subsection{Xác thực JWT}

Hệ thống sử dụng JWT Bearer Token với HMAC-SHA256, hỗ trợ hai loại người dùng (Admin và Owner). Mật khẩu mã hóa BCrypt, Refresh Token lưu trong DB với thời hạn 30 ngày. Frontend dùng Axios interceptor tự động refresh khi token hết hạn.

\subsection{Dịch vụ Text-to-Speech}

Quy trình tạo âm thanh: nhận văn bản và mã ngôn ngữ $\rightarrow$ chọn giọng đọc phù hợp $\rightarrow$ gọi \texttt{edge-tts} tạo file MP3 $\rightarrow$ lưu vào \texttt{wwwroot/audio/} $\rightarrow$ trả URL. File được cache trên disk, chỉ tạo lại khi nội dung thay đổi.

\subsection{Dịch vụ tự động dịch}

Khi du khách yêu cầu ngôn ngữ chưa có bản dịch, hệ thống tự động: kiểm tra trong CSDL $\rightarrow$ gọi Google Translate API dịch từ tiếng Việt $\rightarrow$ lưu bản dịch $\rightarrow$ tạo file TTS cho bản dịch mới.

\subsection{Dịch vụ mã QR}

\begin{lstlisting}[language={[Sharp]C}, caption={Tạo mã QR cho POI}]
public async Task<QRCode> GenerateQRCode(int poiId)
{
    var code = $"VKE-POI-{poiId:D3}-{Guid.NewGuid()
        .ToString("N")[..6].ToUpper()}";
    var qrGenerator = new QRCodeGenerator();
    var qrData = qrGenerator.CreateQrCode(
        $"{_baseUrl}/qr/{code}", QRCodeGenerator.ECCLevel.M);
    using var qrCode = new PngByteQRCode(qrData);
    var pngBytes = qrCode.GetGraphic(10);
    var fileName = $"{code}.png";
    await File.WriteAllBytesAsync(
        Path.Combine(_webRoot, "qrcodes", fileName), pngBytes);
    var entity = new QRCode {
        POIId = poiId, Code = code,
        QRImageUrl = $"/qrcodes/{fileName}", IsActive = true };
    _context.QRCodes.Add(entity);
    await _context.SaveChangesAsync();
    return entity;
}
\end{lstlisting}

\section{Hiện thực Frontend}

\subsection{Quản lý trạng thái}

Ứng dụng sử dụng 5 React Context: \textbf{AuthContext} (đăng nhập/xuất, token), \textbf{ThemeContext} (sáng/tối), \textbf{LanguageContext} (ngôn ngữ hiển thị), \textbf{MapContext} (trạng thái bản đồ), \textbf{VisitorContext} (phiên du khách, kích hoạt, bookmark).

\subsection{Bản đồ tương tác}

Component \texttt{MapView} sử dụng Leaflet hiển thị: bản đồ khu vực Vĩnh Khánh (OpenStreetMap sáng / CartoDB tối), marker đánh dấu POI theo màu danh mục, popup thông tin, tuyến đường tour (polyline), vị trí GPS người dùng, bộ lọc và tìm kiếm.

\subsection{Trình phát âm thanh}

Component \texttt{AudioPlayer}: phát/dừng/tiếp tục, thanh tiến trình kéo được, singleton pattern (chỉ phát một âm thanh), tự động gọi API tạo TTS khi cần.

\subsection{Định tuyến}

Ứng dụng sử dụng React Router với lazy loading và Protected Routes:
\begin{itemize}[nosep]
  \item \textbf{Public:} Trang chủ (bản đồ), chi tiết POI, quét QR, kích hoạt.
  \item \textbf{Admin:} Dashboard, quản lý POI/Tour/Owner/Category/Language/QR/Audio.
  \item \textbf{Owner:} Dashboard, quản lý POI/Menu/QR, thông báo, hồ sơ.
\end{itemize}

\section{Hiện thực Mobile (.NET MAUI)}

Ứng dụng mobile xây dựng bằng .NET MAUI theo mô hình MVVM: Models (dữ liệu API), Services (HTTP client), ViewModels (logic hiển thị), Views (XAML + MAUI Maps). Hỗ trợ Android, iOS, Windows, MacCatalyst.

\section{Đa ngôn ngữ và âm thanh tự động}

Tính năng cốt lõi cho phép du khách quốc tế tiếp cận thông tin bằng ngôn ngữ của họ. Hỗ trợ 22 ngôn ngữ: Tiếng Việt, Anh, Nhật, Hàn, Trung, Pháp, Tây Ban Nha, Đức, Ý, Nga, Bồ Đào Nha, Thái, Indonesia, Malay, Hindi, Ả Rập, Hà Lan, Ba Lan, Thổ Nhĩ Kỳ, Thụy Điển, Philippines, Khmer. Bản dịch và âm thanh được tạo tự động theo yêu cầu và cache lại.

\section{Hệ thống kích hoạt du khách}

Du khách thanh toán 20.000 VND (mô phỏng thẻ tín dụng) để truy cập không giới hạn trong 24 giờ. Hệ thống dùng session-based (không cần tài khoản), heartbeat ping mỗi 5 giây để theo dõi, và tự động hết hạn sau 24h.

\section{Tour ẩm thực}

6 tour có sẵn: Seafood Discovery (90'), Best of Vinh Khanh (120'), Night Food Tour (90'), Family Friendly (60'), Vietnamese Flavors (75'), Coffee Explorer (45'). Mỗi tour gồm các điểm dừng theo thứ tự với ghi chú chuyển tiếp, khoảng cách tự động tính bằng công thức Haversine.

\section{Thống kê và thông báo}

Dashboard Admin/Owner hiển thị: tổng POI, lượt thăm, phân bố ngôn ngữ, biểu đồ theo ngày. Visit Log ghi nhận loại trigger (QR/geofence/manual/search). Audit Log ghi nhận hành động quản trị. Hệ thống thông báo cho Owner (duyệt POI) và Admin (đăng ký mới).

\section{Chế độ sáng/tối và PWA}

Tự động phát hiện tùy chọn hệ thống, chuyển đổi bằng nút bấm, bản đồ đổi tile theo theme. Ứng dụng hỗ trợ PWA, có thể cài đặt trên màn hình chính điện thoại.
